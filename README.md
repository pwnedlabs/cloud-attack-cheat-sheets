# Cloud Attack Cheat Sheets

Phase-by-phase offensive security cheat sheets for the major cloud platforms, with a real, copy-pasteable command for every technique. Each sheet follows the order a real attack path takes, from the first foothold through to impact, then the detection and controls that break each step. Everything here is for authorized testing and defensive work.

Maintained by [Pwned Labs](https://pwnedlabs.io), a hands-on cloud and AI offensive security training platform that teaches these attacks and their defenses in live cloud environments.
